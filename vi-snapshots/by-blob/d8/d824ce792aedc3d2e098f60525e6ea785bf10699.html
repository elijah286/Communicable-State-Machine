CSM Execute - Highlight All Scripts.vi

This VI is part of a plug-in for modifying the LabVIEW shortcut menus. This is the execute VI which is called when the shortcut menu is chosen by the user. It performs the action of the selected menu item.

Menu Item Tag Suffix

Specifies the string to append to the menu item tag. The maximum length of a menu item tag, including the file name of the plug-in and the menu item tag suffix, is 240 characters.

The menu item tag syntax is

APP_SC_PLUGIN_x.vi/menu_item_tag_suffix

where x is the name of the plug-in.

Set this output to TRUE to tell LabVIEW to fail the automatic transaction, if any. Any scripting changes made to the user's VI will be rolled back. If the build VI told LabVIEW to not create a transaction on the user's VI then this output does nothing.
