CSM Execute - Shortcut Menu Plug-In.ctl

This typedef defines the types of refnums that this shortcut menu plug-in will affect. You may:

* Change the type of the existing array element to the specific type of object your menu item should affect. If, for example, you change the array to be an array of Listbox refnums, your menu items will only be added to the Listbox shortcut menus.

* Add one or more additional arrays of a specific refnum types. This will make your menu items appear on shortcut menus of an object that matchs <b>any</b> of those types.

 Affected Items

Specifies the refnum types of the front panel and block diagram objects that the plug-in affects. This control is a type definition that you define in the x.ctl file. The type definition ensures the plug-in VIs use the same object type. You can disconnect <b>Affected Items</b> from the type definition to make the plug-in load faster.
