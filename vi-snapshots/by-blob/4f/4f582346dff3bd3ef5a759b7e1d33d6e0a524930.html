Communicable State Machine.lvlib:CSM - Filter Messages to Non-Existing Modules.vi

Concatenates states in the JKI State Machine. Unwired inputs are safely ignored and will not be added to the state queue.

For instructions on how to use the JKI State Machine, examples and video tutorials, visit:

http://jkisoft.com/state-machine/

Inputs:

State(s) in Front: This allows you to place new states in the front of the state machine queue. The default is an empty string.

State(s) in: Wire the existing states to this input. The default is an empty string.

State(s) in Back: This allows you to place new states in the back of the state machine queue. The default is an empty string.

Outputs:

States Out:This output returns a concatenation of all the inputs seperated by a line feed character. The line feed character is required by the JKI State Machine.
