Menu Item In

Specifies a menu item. The text display, description, icon and event handling command tag can be specified.

    		Menu Name

    Specifies the text that appears in the pop-up menu for the menu item.

    		Description

    Specifies the description that appears in the status bar for the menu item.

    		Icon File Name

    Specifies the location of the icon for the menu item. If left blank no icon will appear with the menu item.

    		Menu Tag

    Specifies the user event "Command Tag" to handle the menu items selection.

    The "mxLvInvokeCommand" user event returns a "Command Tag". If a menu item is selected the tag specified in this control will be returned in "Command Tag".

    		Enabled

    Specifies if the menu item is enabled.

    		Checked

    Specifies if the menu item has a check next to it.

    		Separator

    Specifies if the menu item is a separator.

    		Batchable

    		Weight

    		Batch Mode (Ignored if Not Batchable)

    		Menu Location

    		Exclude From Getting Started Window Menu
