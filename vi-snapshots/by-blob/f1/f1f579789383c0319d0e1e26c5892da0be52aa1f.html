csm-tool-support.lvlib:Autosize All MultiListbox Columns (Uniform Text).vi

This VI resizes each column of the table specified by Table Ref based on the widest entry of the column. Additionally, if Resize Table? is TRUE, the VI will set the table width based on the number of populated columns.
