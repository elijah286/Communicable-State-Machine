JKI-State-Machine-Plus.lvlib:Parse State Queue++.vi

Parses the JKI State Machine state queue and returns the current state that will execute next with the associated arguments.

For instructions on how to use the JKI State Machine, examples and video tutorials, visit:

http://jkisoft.com/state-machine/

Inputs:

State Queue: The entire state queue is wired to this input. This should come from the main JKI State Machine shift register.

Error In The error cluster from the JKI State Machine is wired to this input. If an error occures and appears on this input, the current state output returns the "Error Handler" state.

Outputs:

Remaining States: Returns all the next states that should execute after the current state completes. These should be passed through the current state in the state machine. These can also be modified or augmented within the current state if necessary.

Current State: Returns the current state that should execute next in the state machine. If an error is wired to the Error input then the current state output becomes "Error Handler".

Arguments: Returns any argument(s) that may be used in the current state string. These arguments come after the ">>" characters. Note: The arguments variable must not contain any unprintable characters like linefeed or carriage return.

State Syntax:

StateCategory: State >> Argument

Line Terminator: Line feed

Example:

UI: Help >> About

Where "UI" is the state category

Where "Help" is the state

Where "About" is the argument

Other Examples:

App Data: Initialize

UI: Initialize

Help >> About

Commenting:

To add a comment use "//" or "#" and all text to the right will be ignored

Commenting Example:

UI: Initialize // This initializes the UI

# This whole line is a comment

// Another comment line
