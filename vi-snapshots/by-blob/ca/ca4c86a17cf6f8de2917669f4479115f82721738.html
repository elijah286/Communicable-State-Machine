CSM File Logger.lvlib:Convert File Extension (Path)__ogtk.vi

Converts the file extension of a file. "new ending" will accept an extension prefixed with or without a period, or a blank ("") string.

For example:

file name => c:\temp\data.txt

new ending => "csv" or ".csv"

new filename => c:\temp\data.csv

prev ending => ".txt"

file name => c:\temp\data.txt

new ending => ""

new filename => c:\temp\data

prev ending => ".txt"
